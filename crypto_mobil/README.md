# crypto_mobil

Crypto mobil uygulama — Flutter (Android, iOS, web, desktop).

## Kurulum

```bash
flutter pub get
```

## Çalıştırma

```bash
flutter run
```

## Özellikler

- Home (coin listesi, overview)
- Coin detay (grafik, market istatistikleri)
- Arama
- Watchlist (favoriler)
- Ayarlar

Backend API için repo kökündeki `crypto_backend` kullanılır.
